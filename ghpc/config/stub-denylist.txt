# Symbols the analyzer wants to stub but that we refuse to replace.
#
# The analyzer binds stubs by matching game symbols against runtime handler
# names. Our ELF is symbolized, so it offers 12,663 names to collide with.
# When the game already contains a working implementation, replacing it with a
# runtime handler deletes real behaviour. GetRomName was the first case; this
# is the second.
#
# One symbol per line. Matched against the name before the "@address".

# Sony CDVD filesystem client, statically linked into the ELF.
# sceFsInit is where the SIF RPC bind happens. Stubbing it left the game
# calling sceFsSifCallRpc (real code) against an unbound client, so every call
# returned an error and the game spun in its retry loop forever.
sceFsInit
sceFsReset
_sceFsSemInit
_sceFsSigSema

# The rest of Sony's libfileio. The runtime stubs six of the nine entry points
# (sceOpen, sceClose, sceRead, sceWrite, sceLseek, sceIoctl) and forwards them
# to its own fioOpen/fioRead family, but has no stub for sceGetstat, sceMkdir or
# sceLseek64. That split the filesystem in half: getstat ran the game's real
# code and reached the fileio RPC service, while open was redirected into the
# runtime's own descriptor table and called fioOpen with a path it never
# supplied. Let all nine run for real so one service owns the descriptors.
sceOpen
sceClose
sceRead
sceWrite
sceLseek
sceIoctl

# The newlib allocator. The runtime binds seven levels of it by name and every
# one of them has a real body in the ELF. The outer four alone are not enough:
# _malloc_r reaches sbrk only through malloc_extend_top, whose stub
# (Compatibility.cpp) returns 0 and never grows the heap, so a real _malloc_r
# returns NULL without sbrk ever being entered. MemAlloc__FiPCci falls back to
# plain malloc whenever gCurHeap is null, which is always, so that NULL lands
# in ChunkAllocator and Refill__14FixedSizeAlloc dispatches through a vptr
# that was never written. Un-stub the whole family or none of it.
malloc
free
realloc
memalign
_malloc_r
_free_r
_realloc_r
_calloc_r
_memalign_r
_malloc_trim_r
malloc_extend_top
__malloc_lock
__malloc_unlock
