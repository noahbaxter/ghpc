# Confidence per decompiled function

Generated by `tools/confidence.py`, which is also where the assessments are written down.

Nothing here has been executed. There is no verification harness. These levels are my own reasoned judgement about how much the disassembly constrains the reading, and every row names the evidence.

- **high**: the disassembly admits one reading and at least one independent check agrees (a mirrored function, a serialization order, a recovered assert string, a vtable entry, or a matching RB3 class).
- **medium**: the mechanism is certain, but a name or a semantic reading is inference. Each medium row says which part.
- **low**: none. Anything that would have landed here was dropped rather than written down.
